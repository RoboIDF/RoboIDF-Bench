# 后端独立对照（2026-11-01）

运行 `pixi run --locked python comparison.py` 输出严格 JSON 并保存 `artifacts/comparison.json`；`pixi run --locked test` 运行全部回归。CLI 返回 0 表示预设协议检查通过，其中明确包含应当拒绝的负面对照，不表示每个情景都通过。

Bench 自行生成与评分单自由度数据，对照 M0 线性最小二乘与 Core SciPy 有界自由回放拟合。五个固定情景为无噪声、速度高斯噪声（标准差 0.01 m/s）、未建模弹簧、零激励，以及 `solve_ivp` 连续质量阻尼系统。真实参数仅 Bench 可见，用来报告相对参数误差；Core 接收的数据不携带真值。

训练 seed=101、验证 seed=202、最终测试 seed=501。激励选择仅使用事先声明的名义模型，在同长度候选中按信息量选择；训练数据确定后，两种方法使用完全相同的训练/验证/测试集。预设自由回放 RMSE 阈值 0.025 m/s，拟合与验证完成后才生成最终测试，最终测试不会调参、重启或改变激励。回归还改变最终 test seed，核对拟合报告、baseline 参数和选择结果不变。

报告逐情景保存种子、噪声配置、生成方法、真值、三份数据哈希、两种方法的模型、误差和失败。优化器报告额外给出依赖版本、完整拟合预算与数值诊断。结构失配和零激励必须不通过；无噪声情景两种方法必须通过。噪声与连续情景如实报告，不预先承诺某种算法总是优胜。无激励时没有参数估计，误差使用 null，避免伪造零误差。

这是 M3 软件子集的合成证据，不是完整机器人 Benchmark 或成熟后端排名。连续生成与离散拟合的差异可以形成有效参数偏差；不应把连续情景的参数误差直接理解为恢复真实参数失败。还未接入 MuJoCo、Isaac、真实设备、第三方资产或多关节系统。
