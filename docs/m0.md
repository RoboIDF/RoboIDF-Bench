# M0 Synthetic Suite

三组质量/阻尼真值分别为 (1,.2)、(2,.4)、(4,1.2)，单位 kg 和 N·s/m。训练种子 100–102，最终测试种子 900–902，每轨迹 600 步、dt=.01 s、初始速度 .3 m/s。输入为正弦加均匀随机力。

本项目独立生成轨迹并独立计算自由回放误差，不调用 Core 的 MockRobot 或评估器。拟合只见 train，不见真值和 test。预先固定阈值：每个参数相对误差 <=1e-7、回放 RMSE <=1e-8 m/s；所有案例和零激励拒绝均需通过，进程才返回 0。

这些阈值用于无噪声、同模型回归，不是机器人性能标准。没有噪声鲁棒性、跨仿真器、真实数据或 Agent 评测结论。报告包含阈值、种子、数据哈希和每项结果，不用单一总分隐藏失败。

`pixi run demo` 写入 artifacts/bench.json；`pixi run test` 包含故意错误模型必须不通过的负面对照。升级 Core 时通过 Pixi 修改 Git 提交依赖并更新锁文件，不应为了通过回归修改最终测试种子或阈值。

零值参数误差使用 max(abs(truth),1e-12) 作归一化分母；发散的候选返回 passed=false 与 DIVERGENT_ROLLOUT。每个 case 保存候选模型和真值以供审核。
